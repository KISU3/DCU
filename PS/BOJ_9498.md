# 시험 성적

- **문제 번호:** 9498
- **난이도:** Bronze V
- **사이트:** [백준 온라인 저지(BOJ)](https://www.acmicpc.net/problem/9498)

## 문제

시험 점수를 입력받아 점수에 해당하는 학점을 출력한다.

## 입력

첫째 줄에 시험 점수(0 이상 100 이하의 정수)가 주어진다.

## 출력

시험 점수에 따라 다음 학점을 출력한다.

- 90점 이상 100점 이하: `A`
- 80점 이상 90점 미만: `B`
- 70점 이상 80점 미만: `C`
- 60점 이상 70점 미만: `D`
- 60점 미만: `F`

## 예제 입력 1

```text
100
```

## 예제 출력 1

```text
A
```

## 풀이 접근 방식

### 1. 사용 언어
- C 언어로 구현한다.

### 2. 전역 변수
- 파일 상단에 `int gA;`를 선언하여 입력 점수를 저장한다.

### 3. 함수 설계
- `void board(int score);` 함수를 구현한다.
- `score`의 점수 구간에 따라 해당 학점을 출력한다.
  - 90 이상 100 이하이면 `A`
  - 80 이상 90 이하이면 `B`
  - 70 이상 80 이하이면 `C`
  - 60 이상 70 이하이면 `D`
  - 60 미만이면 `F`
- 점수 구간의 경계값이 겹치므로 `A`부터 내림차순으로 `if-else if` 조건을 검사한다. 따라서 경계 점수는 더 높은 학점에 해당한다.

### 4. main 함수
- `scanf`로 점수를 입력받아 `gA`에 저장한다.
- `board(gA)`를 호출한다.
- 정상 종료 시 `return 0;`을 반환한다.

### 5. 코딩 스타일
- 여는 중괄호는 함수 선언 또는 제어문과 같은 줄에 배치하는 K&R 스타일을 사용한다.
- 불필요한 줄바꿈이나 빈 줄은 넣지 않는다. 코드 구조를 구분하는 데 필요한 줄바꿈은 유지한다.
- 출력에서 줄바꿈이 필요하면 이스케이프 문자 `\n`을 사용한다.
- `\\n`처럼 백슬래시를 두 번 작성하면 줄바꿈이 아닌 문자 그대로 출력되므로 주의한다.
