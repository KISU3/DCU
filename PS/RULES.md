# PS 풀이 작성 규칙

백준(BOJ) 문제의 풀이 문서(`BOJ_<문제번호>.md`)와 C 소스 코드(`BOJ_<문제번호>.c`)를 작성할 때 공통으로 적용하는 규칙이다.

## 1. 사용 언어
- 문제 풀이는 C 언어로 구현한다.

## 2. Markdown 문서 구성
- 파일명은 `BOJ_<문제번호>.md` 형식으로 작성한다.
- 문서 상단에 문제 제목을 `#` 제목으로 작성한다.
- 문제 번호, 난이도, 사이트 정보를 기록한다.
- 문제 설명, 입력, 출력, 예제를 정리한다.
- 마지막에 `풀이 접근 방식`을 작성하고, 구현에 필요한 내용을 구체적으로 기록한다.
- 풀이 접근 방식에는 전역 변수, 함수 설계, `main` 함수의 입력 및 호출 흐름, 코딩 스타일 등을 포함한다.

## 3. C 소스 파일
- 소스 파일명은 Markdown 문서와 동일한 문제 번호를 사용해 `BOJ_<문제번호>.c`로 작성한다.

## 4. 코딩 스타일
- 여는 중괄호 `{`는 함수 선언 또는 제어문과 같은 줄에 배치하는 K&R 스타일을 사용한다.
- 불필요한 줄바꿈이나 빈 줄은 넣지 않는다. 다만 코드 구조를 구분하는 데 필요한 줄바꿈은 유지한다.
- 출력에서 줄바꿈이 필요하면 이스케이프 문자 `\n`을 사용한다.
- `\\n`처럼 백슬래시를 두 번 작성하면 줄바꿈으로 처리되지 않고 문자 그대로 출력되므로 주의한다.

## 5. 풀이 로직 작성
- 문제에서 요구하는 조건과 출력 형식을 정확히 반영한다.
- 서로 겹치는 조건이 있다면 검사 순서를 고려해 조건문을 작성한다. 예를 들어 점수 구간은 높은 점수부터 검사해 경계값이 올바른 구간에 포함되도록 한다.
- Markdown에 기록한 풀이 접근 방식과 실제 C 코드의 변수, 함수, 입력 흐름 및 조건이 일치해야 한다.
