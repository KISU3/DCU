# 두 수 비교하기

- **문제 번호:** 1330
- **난이도:** Bronze V
- **사이트:** [백준 온라인 저지](https://www.acmicpc.net/problem/1330)

## 문제

두 정수 A와 B가 주어진다. 두 수의 크기를 비교하여 결과를 출력한다.

## 입력

첫째 줄에 정수 A와 B가 공백으로 구분되어 주어진다.

## 출력

A와 B의 크기 관계에 따라 다음 기호 중 하나를 출력한다.

- A가 B보다 크면 `>`
- A가 B보다 작으면 `<`
- A와 B가 같으면 `==`

## 예제 입력 1

```text
1 2
```

## 예제 출력 1

```text
<
```

## 풀이 접근 방식

### 1. 사용 언어
- C 언어

### 2. 전역 변수
- 정수형 전역 변수 `gA`, `gB`를 선언한다.
- 입력받은 두 정수를 저장하는 용도로 사용한다.

### 3. 함수 설계
- `void compare(int A, int B);` 함수를 구현한다.
- 함수 내부에서 두 정수의 크기를 비교하고 결과를 출력한다.
  - `A > B`이면 `>`
  - `A < B`이면 `<`
  - `A == B`이면 `==`

### 4. main 함수
1. `scanf`를 사용하여 두 정수를 입력받아 전역 변수 `gA`, `gB`에 저장한다.
2. `compare(gA, gB)`를 호출한다.

### 5. 코딩 스타일
- 중괄호는 여는 중괄호 `{`를 함수 선언과 같은 줄에 배치하는 K&R 스타일을 사용한다.
