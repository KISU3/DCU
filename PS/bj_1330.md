# 두 수 비교하기

- **문제 번호:** 1330
- **난이도:** Bronze V
- **사이트:** [백준 온라인 저지](https://www.acmicpc.net/problem/1330)

## 문제

두 정수 A와 B가 주어진다. 두 수의 크기를 비교하여 결과를 출력한다.

## 입력

첫째 줄에 정수 A와 B가 공백으로 구분되어 주어진다.

## 출력

A와 B의 크기 관계에 따라 다음 기호 중 하나를 출력한다.

- A가 B보다 크면 `>`
- A가 B보다 작으면 `<`
- A와 B가 같으면 `==`

## 예제 입력 1

```text
1 2
```

## 예제 출력 1

```text
<
```
